# ADR-0003: Закреплённый футер панели управления

Статус: принято (accepted)
Дата: 2026-08-20

## Контекст
Панель управления не показывала версию приложения и не имела постоянного
места для служебных ссылок (справка). Версия упоминалась только в
коммитах/README, пользователь не мог узнать её из интерфейса.

## Решение
В `js/ui.js` добавлен закреплённый (sticky) футер внутри панели: строки
«Панель управления», «Версия v0.1», «Справка». Футер не скроллится вместе
со списком опций и всегда виден внизу панели.

## Альтернативы
- Версия в `<title>`/README без отображения в UI — отклонено, пользователю
  неудобно искать версию вне интерфейса.
- Модальное окно «О программе» — избыточно для одной строки версии.

## Последствия
- Версию в футере нужно обновлять вручную при каждом релизе (сейчас
  зафиксирован текст «v0.1», требует правки при выпуске 0.2 — см. задачу
  на подготовку релиза).
- Место для «Справки» зарезервировано в разметке, содержимое справки не
  входит в эту ADR.
