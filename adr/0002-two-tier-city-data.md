# ADR-0002: Двухуровневая система городов и отдельный тумблер «Столицы»

Статус: принято (accepted)
Дата: 2026-08-20

## Контекст
После v0.1 на карте был только один набор городов (`RU_CITIES` + верхнеуровневый
список). Требовалось показать больше населённых пунктов (столицы топ-50 стран
по площади, крупные города >1 млн для топ-10 по населению) без перегрузки
карты при обычном просмотре.

## Решение
Введён второй уровень данных `CITIES2` (`js/data.js`): столицы + крупные
города, отдельный от базового списка `RU_CITIES`/городов 1-го уровня.
На панели (`js/ui.js`) добавлена отдельная опция «Столицы», независимая от
переключателя «Города» — уровни включаются/выключаются раздельно
(`js/main.js`). Точки городов 1-го уровня уменьшены на 65% размера, сделаны
круглыми, прозрачность 25%, подписи 2-го уровня — без рамки, фон светлее и
прозрачнее на 50% (`index.html`), чтобы визуально не конкурировать с
основным слоем при совместном включении.

## Альтернативы
- Один общий список городов без деления на уровни — отклонено: не даёт
  раздельного управления плотностью точек на карте.
- Полностью отдельный слой/рендер-путь для 2-го уровня — избыточно для
  текущего объёма данных (~10 городов на страну).

## Последствия
- `js/data.js` — два независимых источника городских данных, при
  расширении списка стран нужно решать, в какой уровень добавлять.
- UI получил дополнительный чекбокс, дальнейшие уровни (если появятся)
  должны следовать тому же паттерну (данные в `data.js`, тумблер в
  `ui.js`, применение в `main.js`).
