# ADR-0004: Дефолты видимости слоёв и скорость сценария ракеты

Статус: принято (accepted)
Дата: 2026-08-20

## Контекст
Два независимых, но однотипных решения о параметрах по умолчанию,
собранные в одну ADR как «настройки поведения по умолчанию»:
1. Слой «Электростанции» был включён по умолчанию и визуально перегружал
   карту при первой загрузке.
2. Сценарий запуска ракеты (`ROCKET_SPEED_MUL`) шёл слишком медленно
   относительно других анимированных объектов (спутники, самолёты).

## Решение
- `js/main.js` / `js/ui.js`: слой «Электростанции» переведён в состояние
  «выключено» по умолчанию, включается пользователем вручную через панель.
- `js/main.js`: `ROCKET_SPEED_MUL` увеличен с 5 до 15 (в 3 раза) —
  сценарий ракеты синхронизирован по темпу с остальными сценариями.

## Альтернативы
- Убрать электростанции из первого релиза совсем — отклонено, слой нужен,
  просто не должен быть навязан по умолчанию.
- Сделать скорость ракеты настраиваемой через UI — не сделано, признано
  избыточным для текущего масштаба анимации.

## Последствия
- Любой новый слой по умолчанию должен явно решать вопрос
  «включён/выключен» на старте, ориентируясь на этот прецедент
  (электростанции — выключено).
- Изменение `ROCKET_SPEED_MUL` — точечная числовая правка, не требует
  отдельного тестового покрытия.
