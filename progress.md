# earth-3d — progress

Файл: `index.html` (один файл, three.js r0.128 с CDN, ~790 строк).

## Сделано (последняя сессия)
- МКС (issMesh) на отдельной низкой орбите (issOrbit), клик по ней (issHit) —
  космонавт (cosmonaut) выходит наружу и возвращается (updateCosmonaut).
- Космодромы (COSMODROMES: Байконур, Канаверал, Плесецк, Восточный, Куру) —
  маркеры кат. 'cosmodrome', цвет #ff8a5c.
- Ракеты (rocketPool, 2 шт, updateRockets): раз в 15-35с старт со случайного
  космодрома → подъём (ascend) → переход в мировые координаты к МКС (transfer)
  → стыковка на 8с (docked) → отстыковка и улёт (undock) → idle, повтор.
- Клик для выбора планеты/Луны/Солнца теперь работает и по названию (label),
  не только по поверхности (selectTarget() вынесена в функцию, labelObj click).
- Танкеры/корабли теперь идут по ломаной из нескольких точек (SHIP_ROUTES,
  TANKER_ROUTES — маршруты через Ормузский/Малаккский проливы, огибают сушу),
  а не по прямой между двумя портами. updateSeaCraft ходит по всей ломаной
  за один цикл t:0→1.

## Архитектура (кратко)
- Земля/облака/ночные огни/атмосфера — в начале файла.
- CITIES/LANDMARKS/PLANTS/RU_CITIES/COSMODROMES — данные маркеров,
  addMarker() создаёт dot+label+hit, tierOf() — LOD видимости подписей.
- Спутники/самолёты/корабли/танкеры — мировые координаты или дочерние earth.
- Солнечная система (PLANETS, solarBodies) + selectable[] — клик меняет
  center камеры (controls.target).
- animate() — общий тик, все update* вызываются там.
