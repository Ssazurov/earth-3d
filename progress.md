## Issue #25: Видеозвонок 1:1 по ссылке (реализация)
- Новый модуль `js/call.js` (initCall()) — полностью самодостаточный: свои
  стили и DOM (кнопка внизу слева, панель с видео/статусом/управлением),
  не импортирует и не трогает three.js-сцену/панель — можно вынести в
  отдельное приложение/iframe без переписывания логики (см. ADR 0006).
- index.html: подключён PeerJS UMD (cdn, peerjs@1.5.4) до `js/main.js`.
- main.js: `initCall()` вызывается один раз при старте, отдельно от
  остальной инициализации сцены.
- Логика: без `?call=` в URL — кнопка "Позвонить" создаёт Peer, получает
  getUserMedia, генерирует ссылку `?call=ID` (показывается + копируется),
  ждёт входящий call и отвечает своим stream. С `?call=ID` — кнопка
  "Присоединиться" получает getUserMedia и звонит по этому id.
- Локальное/удалённое видео — DOM `<video>` в углу экрана (не WebGL),
  toggle камеры/микрофона (enabled на треках), кнопка "Завершить"
  останавливает треки, закрывает call и peer.
- ⚠️ Не проверено в браузере (нет доступа к камере/двум вкладкам в этой
  среде) — проверить вручную на http://localhost:8080/index.html.

## Исправление чёрного экрана удалённого видео
- Проблема: remote видео получает поток с активными треками, но остаётся чёрным из-за autoplay policy браузера (Chrome блокирует unmuted autoplay).
- Решение: временно mute все видео при создании, после успешного `.play()` unmute только remote (local остаётся muted).
- Изменения: `js/call.js` — `addVideo()` теперь ставит `v.muted = true` для всех, затем в `.then()` после `play()` снимает mute только для `!isLocal`.
- Проверено: `node --check js/call.js`.

## Исправление невозможности подключения гостя к звонку
- Проблема: `new Peer()` без явного id обращался к `0.peerjs.com/peerjs/id` за генерацией ID — сервер вернул 403/CORS, гость не мог создать Peer вообще.
- Решение: генерируем id на клиенте (`genPeerId()`), передаём его первым аргументом в `new Peer(id, {...})` — запрос к серверу за id больше не нужен.
- Файлы: `js/call.js` (host и guest ветки).
- ⚠️ Не проверено в браузере (только `node --check`).
